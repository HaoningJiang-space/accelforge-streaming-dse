# 服务层图的一天筛选（2026-11-14）

筛选问题：相对最强基线，哪个跨节点联合决策还没有人做，并且在允许理想调度、求解免费的前提下，乐观收益仍然显著？每个候选需要给出三项：未解决的联合决策、最强基线、乐观收益上界。

| 候选 | 最强基线（文献） | 尚未解决的联合决策 | 乐观上界 | 判定 |
|---|---|---|---|---|
| 前缀共享树上的 attention | Hydragen（ICML'24）、cascade inference、DeFT（ICLR'25）：每个共享 KV 节点每步只读一次，KV IO 减少 73–99% | 给定 SRAM 时，树上分组的最优划分（DeFT 是启发式分组加负载均衡） | KV 读取已经接近只读一次的下限，剩下的只有 query 和部分结果的流量，约 ≤1.1× | 停 |
| 投机解码树 | Sequoia：动态规划构树，并考虑硬件上的树大小和深度 | 树形状与映射联合 | 已被 DP 覆盖 | 停 |
| MoE 专家放置与路由 | MoETuner（ILP，联合负载、通信和计算；+9–18%）、GRACE-MoE（最高 3.79×）、CAP | 放置与路由联合（已有 ILP 精确形式） | 没有找到明显的剩余空间 | 停 |
| agent 工作流 DAG | Parrot、Autellix、KVFlow、Teola、Halo、TOPAS、Helium、TAO、Continuum、UNISON、TokenDance（2024–2026，十余个系统） | 调度、KV 驻留与路由联合 | 已有工作覆盖密集；收益来自调度和缓存，和图结构简化精确搜索无关 | 停 |

结论：服务层的图确实不是链，但最强基线已经拿走大部分收益，而且这些问题和已有正结果（图结构让精确映射搜索变简单）没有连接。四个候选都不继续。
