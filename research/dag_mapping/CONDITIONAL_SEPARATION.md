# 条件分解审计：驻留边界后的连续独立区域

本轮承接 `55d96170` 的组合结果。目标是检查强基线剩余工作中，是否存在“父响应不同，
但只有部分分支需要变化”的结构。先证明充分条件并检查覆盖，不建立新的默认优化器。
沿用 `research/main`，不增加分支；生产 `graph/curve.py` 不变。

## 1. 范围与候选规则

固定原生 v2 Grammar：合法固定总顺序、单写者、一致的张量秩、串行、不重算、默认计费、
精确完整前沿、无限 max_capacity、没有 root_groups/root_kept/whole_span_cuts 或 grid。
halving 与 divisors 均可，但一次求解固定一种域。状态是 **solve** 入口的
`(S, ext, R, W)`；R 的容量及对应传输由调用者承担，W 是原有写归属。
所有算子的完整迭代域，包括仅由驻留张量携带的秩，都必须保留。

给定连续划分 `S = S1 ... Sk`。若对任意非驻留张量 t：

    t ∉ R  =>  所有在 S 中访问 t 的算子都属于同一个 Si，

则称它是一个驻留边界分解。等价地，每个切口的跨界张量都是 R 的成员。
用每个非驻留张量的首次/末次位置做区间差分，可以在线性于访问关联数与算子数的时间内
找到全部这种切口，得到最细连续划分。不能把不连续的连通分量重排成连续区域。

候选仅包含 k>1 且至少一个 Si 有多个算子的状态。全是单算子的情况已经由强基线
`independent_ops` 覆盖，不能重新计作新增机会。

## 2. 条件分解命题

令 Fi 为 Si 在投影后的 `(ext, R, W)` 下的完整 solve 额外流量响应。保留原图全局角色。
则在上述语法内：

    F_S = ND { (max_i p_i, sum_i q_i) : (p_i,q_i) ∈ Fi }.

这里不增加跨区域保留量：所有跨区域张量都已由调用者 R 预留。也不重复计根 compulsory。
若某个跨区域张量还未驻留，命题不适用；不能把它的未来成本视为零。

### 从完整计划到区域计划

把完整计划投影到每个连续 Si，对 Leaf/Hold、Partition、Loop 结构归纳：

* Leaf/Hold 只留下 Si 访问的非驻留单元，仍可用相应标量叶子或 Hold 实现。
* Partition 与 Si 求交，删除空的子跨度。任何非驻留张量只出现在一个区域，因此其
  Keep/DRAM 决定、写归属及全部使用位置都保留在同一投影中。驻留的跨区域张量
  不产生新的本地计费。若多层 Partition 形成相邻分组，可把分组及私有边界决定连接。
* Loop 的非空投影仍沿同一合法秩与 tile 执行。共同秩对算子子集仍是共同秩；投影后
  内部非驻留张量的合法性条件是原条件的子集。Keep 只保留该区域访问的私有张量；
  其 reservation、refetch/partial-sum 项都不会被分配给另一区域。完整迭代域不能删除。

于是区域投影计划各自峰值不大于完整峰值，额外流量之和不大于原流量。
局部的最优前沿还可以进一步支配这些投影。因此组合前沿支配任意原计划。

### 从区域计划到完整计划

串行连接区域 solve 计划，顺序不变。对非标量区域，将其顶层 Partition 的组展开成
同一个父 Partition；各区域的 kept/dropped 私有集合互不相交。对标量区域，可以
作为 proper scalar group 保留其原 Partition/Hold，这正是 v2 允许的行为。
每份跨区域数据已经由父级预留，私有数据不越过区域边界，所以峰值取 max、流量相加。
构造落在原生语法内。这给出反向可实现性，两个方向共同得到前沿相等。

### 不能推广的情况

* **group 入口**不能直接这样分解。两个互不共享张量、分别只有 I/J 秩的非标量算子，
  solve 可串行执行，整个 group 却没有合法共同循环，响应为空。
* 同一私有连通分量在固定顺序中交错出现时，不能跳过其间算子后再连接。两阶段 Join
  的 E0,H0,E1,H1 与 E0,E1,H0,H1 因而有不同的可分解切口。
* 该命题不是任意时刻 yield 接口，也没有消去尚未驻留的共享张量决策。
* 它允许把一部分跨区域循环换成等价或更优的串行区域计划，前提是每条跨区域数据关系
  都已由 R 承担。不能借此强迫 D1 的一般边界物化；不合格状态仍保留全部原生嵌套循环。

## 3. 不同父响应怎样共享局部响应

固定上述分解及边界 R 的跨区域部分。如果只改变 Si 私有输入 t 的驻留状态，则其他
Sj 的投影状态不变，其完整响应可以保持原样。Fi 和全局前沿可以改变：这里不要求
两个父响应相等。调用者新增的 |t| reservation 必须由调用者计入，不能用不同 R 的
局部容量直接宣称完整计划优劣。

审计只在实际强基线访问的成对状态上检查这种变化，并同时保存父响应不同的例子。
这是一条充分条件；它尚未给出一般 DAG 的小边界保证或复杂度上界。

## 4. 审计协议与计数边界

案例固定为已有的 two_stage_join、asymmetric_join、mixed_join；使用与上一轮完全
相同的已认证全局顺序代表元。强基线为 Prefix + independent_ops，启用 parent frames
和 numeric prefix composition，不加入解析替换或其余开关。

本轮是描述性结构审计，不是新算法性能实验。开发阶段已本地查看 two_stage_join
以验证记录器；因此不把后续覆盖率叫作未见数据的预测成功。远端正式结果使用提交冻结
源码，记录全部声明源码哈希；不依据结果改变案例或规则。

1. 记录 solve、group **以及 prefix_cached** 的所有缓存调用边、每个 miss 的前沿与
   独占 DP/Loop/Pareto/Merge 计数。与普通强基线逐顺序前沿相等，计数总和必须闭合。
   Prefix 节点不能省略，否则共享子响应会被错误地重复计入可删除工作。
2. 对每个合格状态，用独立原生闭包求各区域的 solve 响应，再组合，要求完整前沿相同。
   不用截取子图的方式改变全局 Tensor Role。报告非标量 live、非标量共享 X 的覆盖。
3. 保存最多三个条件构造示例，优先非标量 X 与非标量 live 状态，并记录传入循环。
   用独立类型解释器检查组合后的条件 witness。检查所有可配对私有输入翻转，保存
   “父响应改变、另一分支的完整查询键不变”的实例。
4. 在单独的正确性运行中，以 native oracle 构造的区域响应替换合格 solve，要求每个
   完整根前沿相等；全部生成的根 witness 做 cell 执行及类型资源验证。该替换器通过
   独立 oracle 恢复区域计划，**不是待计时的实现**，其耗时不用于速度结论。
5. 报告零成本替换的工作上限，按调用 DAG 重新计算可达性，保留仍被其他调用者使用的
   子节点；再报告加入区域子查询依赖后的、更严格的零组合成本上限。若区域查询原先
   不存在，明确计数，后一上限也把它们看作免费，不能充当实际预测。

所有上限都没有包含分解识别、响应组合和 witness 构造成本。计数是工作量，不是执行
计划数量；单次插桩 own_seconds 只作诊断，不是未插桩 wall-clock 的精确拆分。
不能把多个状态的递归耗时直接相加，也不能把单个最好顺序的比例冒充全案例比例。

交付为：受限命题、反例守卫、完整条件核对、全根见证和工作上限。之后才决定是否值得
另行冻结一次高效实现实验；本轮不自动更改默认求解器，不恢复 Gate 2/3。
