# 工作量加权的充分性普查，以及由此导出的下闭集递推

## 1. 为什么先普查

Gate 2 证明了跨顺序共享闭合响应是精确的，但几乎不省时间。根因是：被合并的大多是便宜的
小状态。所以在实现任何共享之前，先回答两个问题：

1. **充分性**：一个候选共享键分出的每一类里，响应是否确实相同？只有相同，才能精确共享。
2. **工作加权上限**：只计充分的类，能省下多少独占工作？每类省下的是该类成员工作之和减去
   其中最贵的一个。

工具是 `work_census.py`，在 PyTorchSim 主机上运行。代码是 `5b42c8e1` 的干净克隆，
记录见 `results/work_census/census.jsonl`。

- **基线**：先用自动同构约简全局顺序，再对每个代表顺序用原生 v2 cut DP 求解，并用
  C2 审计的记录器记下每个状态的前沿和独占工作。原生做法下，每个顺序各有一份缓存，
  所以出现在 k 个顺序里的状态要付 k 次工作。
- **不含前缀共享**：前缀共享改变的是状态内部的构造。这里的上限针对的是状态之间的共享。

## 2. 结果（DP 转移）

| 案例 | 代表顺序 | 状态 | 跨顺序、完全相同 | 同构重命名 | 忽略内部顺序：可共享 / 被挡住 |
| --- | ---: | ---: | ---: | ---: | --- |
| Fork–Join tiny | 1 | 1,413 | 0 | 0.8% | 0 / 0 |
| 两阶段 Join | 3 | 15,132 | 3.5% | 5.0% | 11.2% / 47.5% |
| 非对称 Join | 10 | 57,332 | 8.3% | 8.4% | 8.3% / 74.0% |
| 混合 Join | 6 | 46,004 | 4.2% | 23.3% | 29.3% / 44.4% |
| M8 FFN 一层 / 两层 | 1 | 2,108 / 6,176 | 0 | 0 | 0 / 0 |

说明：

- "被挡住"指同一类里响应不同的那部分重复工作，不能靠共享相同响应来消除。
- 循环选择（loop choices）上的上限更高，例如混合 Join 的同构重命名为 52.6%。
- 详见 jsonl。

## 3. 读法

- **普查预测了 Gate 2 的结果。**跨顺序完全相同这个键的上限只有 3.5–8.3%，实测时间改善为
  0.4–4.7%。
- **重复工作的大头在"算子集合相同、内部顺序不同"的状态上**，占 44–74%。这些响应确实
  不同，所以"共享相同响应"这条路不通。
- **单一顺序的链（M8）上，所有键都是 0。**那里的工作不是跨顺序重复。

## 4. 导出的下一步：对无序集合直接求并集（下闭集递推）

父问题最终需要的是各顺序结果的 Pareto 并集，根前沿本身就是这样定义的。因此，不必分别求
每个顺序，再试图合并相同的响应，而是对每个**无序**的算子集合直接计算：

    F(S, 上下文) = Pareto ∪_{S 的合法内部顺序 π} F_native(π, 上下文)

递推方式是把"沿固定顺序切分"换成"沿 S 的下闭集推进"：

- **状态**：已执行的下闭集 D，加上跨越 D 边界的张量的保留或 DRAM 决定。
- **转移**：追加一个组 G。要求 G 的前驱都在 D 中，G 内取一种拓扑序；组的响应仍用原生
  group 求解，组内部的划分同样按本递推对无序集合求并集。

**精确性论证（待写成正式证明并测试）：**

1. **一一对应。**任意"全局拓扑序 + 连续分组"对应唯一一条下闭集链，加上每组的内部顺序。
   反之，任意满足前驱条件的链和组内拓扑序，拼起来都是合法的全局拓扑序。
2. **跨组代价只依赖集合。**边界张量的 DRAM 读写、写所有权，以及保留张量在哪些组之间占用
   单元，只取决于每个张量的生产者和消费者落在哪些组中。这由链决定，与组内顺序无关。
3. **内层取并集不改变结果。**父层组合 d + r·R(C − a) 对 R 单调，兄弟组在给定边界决定后
   相互独立，所以在内层取并集，等于在外层对所有顺序取并集。

**它针对的问题**：全局顺序的枚举，以及"同一集合、不同内部顺序"的重复。这两项都列在 Gate 2
的未解决清单里。

**它不针对的问题**：驻留集合的组合，以及 D1 中作用于不同算子集合的嵌套循环。

**上限**：可共享部分加被挡住部分，约 59–82% 的 DP 工作。这个上限偏乐观，因为下闭集
递推本身要枚举更多的转移，所以必须冻结协议后实测。

**下一步**：先冻结协议，内容包括：

- 精确性检验：与原生的全顺序并集逐点比较，并重放 witness；
- 效率判据：相对于对称性约简加前缀共享这一最强对照；
- 停止规则。

然后再实现原型。
